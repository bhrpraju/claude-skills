# UX Cognitive Architect

> Elite UX/UI design skill grounded in cognitive psychology, behavioral economics, and production-grade visual design laws.

Every design decision traces back to how the human brain actually works — not aesthetic preference, not trends, not generic AI defaults.

---

## What This Skill Does

Most AI design tools jump straight to code. This skill forces a structured diagnostic first:

1. **Who is the user?** — persona, emotional state, device, context
2. **What cognitive laws apply?** — Hick's, Fitts's, Jakob's, Tesler's, Gestalt
3. **What are the psychological stakes?** — Norman's three levels, Six Minds framework
4. **What are the exact visual specs?** — 8px grid, HSL color logic, shadow elevation system
5. **Then and only then** — production-ready code in the right format for your platform

---

## When to Use This Skill

Trigger this skill when you need to:

- Design a screen, page, dashboard, or component from scratch
- Evaluate an existing UI ("what's wrong with this design?")
- Review a wireframe before building
- Choose colors, typography, or spacing systematically
- Design an onboarding flow, form, or checkout sequence
- Audit a layout for cognitive load or conversion issues
- Write design specs for a developer
- Ask "is this good UX?" about anything

**Trigger phrases:**
- "Design a screen for..."
- "What should this UI look like?"
- "Is this good UX?"
- "Improve this design"
- "Audit this layout"
- "What's wrong with this interface?"
- "Build me a component for..."
- "Help me choose colors for..."
- "Design an onboarding flow for..."

## The 4-Stage Output Pipeline

Every response follows this mandatory sequence — no skipping:

Stage 1 — COGNITIVE DIAGNOSTIC
  Persona + End Goal + Experience Goal
  Six Minds assessment
  Norman's Visceral / Behavioral / Reflective
  Hook Loop (if retention is required)

Stage 2 — STRUCTURAL ARCHITECTURE
  Layout strategy
  Hick's / Fitts's / Jakob's / Tesler's / Gestalt applied explicitly
  Information hierarchy

Stage 3 — GRANULAR UI SPECS
  Typography scale (px values)
  Spacing (8px grid values used)
  HSL color palette
  Shadow elevation levels

Stage 4 — BUILDER BLUEPRINT
  Production-ready code in platform-appropriate format

## Cognitive Laws Applied

| Law | What It Enforces |
|---|---|
| Hick's Law | Max 5-7 nav items. Progressive disclosure for advanced options. |
| Fitts's Law | Primary CTA large + thumb-reachable. Destructive actions separated. |
| Jakob's Law | Match established conventions. Flag any intentional deviation. |
| Tesler's Law | Absorb complexity. Never pass it to the user. |
| Gestalt | Proximity, similarity, closure — explicit grouping rules. |
| Norman's Levels | Visceral, Behavioral, Reflective. Design for all three. |
| Fogg Behavior | Behavior = Motivation + Ability + Prompt. |
| Six Minds | Vision, Wayfinding, Memory, Language, Decision Making, Emotion. |

---

## Visual Rules Enforced

- Spacing: 8px grid only — values: 4, 8, 12, 16, 24, 32, 48, 64, 96px
- Color: HSL logic — darkening = lower lightness + increase saturation
- Typography: Modular scale, weight + contrast for hierarchy (not just size)
- Shadows: 4 elevation levels — button, dropdown, card, modal
- No generic AI aesthetics: No Inter-everywhere, no purple-blue gradients, no nested card soup
